PARKCONTROL — SISTEMA DE CONTROLE DE ESTACIONAMENTO
Projeto acadêmico desenvolvido com HTML, CSS e JavaScript puro.

COMO EXECUTAR
1. Extraia todos os arquivos da pasta compactada.
2. Abra o arquivo index.html em um navegador atualizado (Chrome, Edge ou Firefox).
3. Não é necessário instalar programas, frameworks ou dependências.

FUNCIONALIDADES
- Visão geral com total de vagas, ocupadas, disponíveis e taxa de ocupação.
- Cadastro de reserva com placa, nome do proprietário, apartamento, bloco, modelo, cor e número da vaga.
- Validação dos campos obrigatórios e prevenção de duas reservas na mesma vaga.
- Listagem das reservas cadastradas.
- Busca por nome, placa ou modelo do veículo.
- Exclusão de reserva, liberando novamente a vaga.
- Mapa das 12 vagas, identificando vagas disponíveis e ocupadas.
- Armazenamento local no navegador usando localStorage.

TECNOLOGIAS
- HTML5 para estrutura.
- CSS3 para aparência e responsividade.
- JavaScript para validações, navegação e regras de funcionamento.
- localStorage como armazenamento local, pois o desafio não exige back-end.

OBSERVAÇÃO
Os dados ficam salvos no navegador e não em um banco de dados on-line. Para demonstrar o projeto em outro computador ou navegador, será necessário cadastrar novamente os dados.

ENTREGA
Envie a pasta do projeto para um repositório GitHub e compartilhe o link do repositório na plataforma do SENAI.
